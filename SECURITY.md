# Política de Segurança · Security Policy

## Versões suportadas · Supported versions

O **CapivaraOS HERD Community** recebe correções de segurança na série estável
atual (**1.x**, base Fedora 44). Mantenha o sistema atualizado com `dnf upgrade`.

| Versão / Version | Suporte / Support |
|---|---|
| 1.x | ✅ |
| < 1.0 | ❌ |

---

## Como reportar uma vulnerabilidade (PT)

**Não abra uma issue pública para falhas de segurança.** Use um canal privado:

1. **GitHub — _Report a vulnerability_** (recomendado): na aba **Security** deste
   repositório, clique em *Report a vulnerability* (Private Vulnerability
   Reporting). É privado e estruturado.
2. **Alternativa:** se você não usa GitHub, fale com o projeto pelo
   [formulário de contato](https://capivaraos.org/pt/contato.html) **apenas para
   estabelecer contato** — não inclua os detalhes técnicos da falha ali;
   combinaremos um canal privado para os detalhes.

Ajuda muito incluir: versão (`cat /etc/os-release`), passos para reproduzir,
impacto e, se possível, uma prova de conceito.

**O que esperar:** confirmamos o recebimento assim que possível, avaliamos e, se
a falha for confirmada, trabalhamos numa correção e coordenamos a **divulgação
responsável** junto com você. Por ser um projeto comunitário, respondemos em
regime de **melhor esforço** — por favor, dê um prazo razoável antes de divulgar
publicamente.

## How to report a vulnerability (EN)

**Do not open a public issue for security flaws.** Use a private channel:

1. **GitHub — _Report a vulnerability_** (recommended): in this repository's
   **Security** tab, click *Report a vulnerability* (Private Vulnerability
   Reporting). It is private and structured.
2. **Alternative:** if you don't use GitHub, reach out via our
   [contact form](https://capivaraos.org/en/contact.html) **only to establish
   contact** — do not include the technical details of the flaw there; we'll
   agree on a private channel for the specifics.

Helpful details: version (`cat /etc/os-release`), steps to reproduce, impact and,
if possible, a proof of concept.

**What to expect:** we acknowledge reports as soon as possible, assess them and,
if confirmed, work on a fix and coordinate **responsible disclosure** with you.
As a community project, we respond on a **best-effort** basis — please allow a
reasonable time before public disclosure.
